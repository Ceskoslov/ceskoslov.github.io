# ceskoslov.github.io

A static personal site generated by [Zola](https://www.getzola.org/).

## What's Inside

- Zola and Tera templates, built with a single binary
- Markdown posts with TOML front matter
- Home, post, archive, tags, about, and 404 pages
- Atom feed, sitemap, robots.txt, and social sharing metadata
- Responsive navigation, dark and light themes, print styles, and reduced-motion support
- GitHub Actions for automatic builds and deployments to Pages
- No third-party fonts or front-end JavaScript frameworks

## Installing Zola

```bash
cargo install --locked --git https://github.com/getzola/zola
```

Alternatively, download a pre-built binary from [Zola Releases](https://github.com/getzola/zola/releases), or use snap on Ubuntu/WSL:

```bash
sudo snap install zola --edge
```

To verify the installation:

```bash
zola --version
```

## Local Preview

```bash
zola serve
```

Open `http://127.0.0.1:1111` in your browser. The page will automatically refresh when you save changes to Markdown, templates, or CSS.

To preview drafts together:

```bash
zola serve --drafts
```

To check and build the site:

```bash
zola check
zola build
```

The generated site is located in `public/`, which is ignored by Git.

## Writing a Post

Create a Markdown file in `content/writing/`. Use a date followed by a descriptive, lowercase English slug, for example `2026-08-14-my-new-post.md`:

````markdown
+++
title = "Title"
date = 2026-08-14
description = "A short description that appears in search results and on the homepage."

[taxonomies]
tags = ["Tech", "Notes"]
+++

Begin writing your post here.

## Secondary Title

Markdown, tables, and syntax-highlighted code are supported.

```rust
fn main() {
    println!("hello, chaos");
}
```
````

The order of posts is determined by the date in the filename.
Include `draft = true` in the front matter to mark it as a draft.

### Inserting Images

Place images in `static/assets/images/posts/` and use them in your posts:

```markdown
![Image description](/assets/images/posts/example.jpg)
```

## Deploying to GitHub Pages

The repository already contains `.github/workflows/pages.yml`. To deploy:

1. Open the GitHub repository's **Settings → Pages**.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. Commit and push to the `main` branch.

Actions will install Zola, build, and deploy `public/`. The site URL is `https://ceskoslov.github.io` when the repository name is `ceskoslov.github.io`.

If the default branch is not `main`, modify `branches` in the workflow. If you change the GitHub username, update `base_url`, `author`, and `github_username` in `zola.toml`.

## Customization

Site information is in `zola.toml`, the about page is `content/about.md`, and theme variables are at the top of `static/assets/css/style.css`:

```css
:root {
  --paper: #f2efe6;
  --ink: #11110f;
  --accent: #c92f24;
}
```

│   └── archive.md       # Archive page
