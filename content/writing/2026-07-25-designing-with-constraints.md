面对一张空白画布，我们很容易误以为自由越多，结果就会越好。但实际工作中，好的方案通常来自一组清楚的限制。

## 限制减少噪声

假设一个页面只允许使用一种字体、两种字号和一个强调色。决定会变少，注意力便自然回到内容层级、间距和节奏上。

这也是本站视觉系统的基本规则：

| 元素 | 约束 |
| --- | --- |
| 色彩 | 中性色加一个橙色强调 |
| 排版 | 衬线负责叙事，无衬线负责结构 |
| 动效 | 只回应用户操作 |
| 布局 | 网格清楚，但允许局部错位 |

## 规则也需要出口

约束不是教条。只有当规则足够明确，偏离规则才会显得有意义。标题中的斜体、边缘的一枚圆点，或者稍微倾斜的标记，都是从秩序中短暂逃逸的信号。

```css
.order {
  display: grid;
  gap: 1px;
}

.chaos {
  transform: rotate(-3deg);
}
```

先建立系统，再选择在哪个地方打破它。这大概就是我理解的设计。
